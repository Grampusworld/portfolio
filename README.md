# Grampus 磁带作品集

像素风个人游戏作品集：草地上的皮质磁带收纳包 + 老式磁带机。把磁带插进播放机，详情屏显示作品的演示、介绍、标签和链接。

**在线地址**：https://grampusworld.github.io/portfolio/ （推送到 `main` 后由 `.github/workflows/deploy.yml` 自动构建部署）

## 运行

```bash
npm install
npm run dev        # http://localhost:5177
npm run build      # 产物在 dist/，相对路径，可直接丢到任意静态托管（含 GitHub Pages 子路径）
```

调试参数：`?state=play2` 直接播放第 2 个作品；`?rm=1` 模拟「减少动态效果」；`?freeze=0.4` 把磁带飞行定格在 40%；`?debug=1` 左下角显示状态；`?fuzz=20` 随机连点 / 拖拽 20 秒后检查状态是否一致。

测试脚本（需先 `npm run dev`）：

```bash
node tools/fuzz.mjs http://localhost:5177/ 20 3                      # 压力测试 3 轮
node tools/snap.mjs "http://localhost:5177/?state=play1" out.png 1280 720   # 真实时间截图
```

## 改内容

| 要改的 | 位置 |
|---|---|
| 作品（3–6 个）：编号、磁带标签名、外壳色、全名、一句话介绍、标签、链接、媒体 | `src/works.js` |
| 详情屏片段 / 放大视频 / 循环兜底 / 封面 | `public/media/<id>/clip.mp4`、`full.mp4`（可选）、`loop.mp4`、`poster.webp` |
| 两套版式的坐标（320×180 桌面 / 180×320 手机竖屏） | `src/layout.js` |
| 调色板和所有像素素材（程序生成） | `src/art.js` |
| 背景风声 / 草声和所有音效（Web Audio 实时合成，无音频文件） | `src/audio.js` |

**改了任何文案后要重新裁字体**：`pip install fonttools brotli && npm run font`（10px 正文字 + 8px 标签字，只保留页面用到的字，共约 39 KB）。磁带标签名 8px 字宽度不超过 34 像素（约 4 个汉字或 7 个英文字母）。外壳色可选 `rain` / `night` / `echo` / `dawn`，新增配色在 `art.js` 的 `SHELL` 里加。没有链接的按钮自动隐藏。

视频规格：
- `clip.mp4`：详情屏播放、快进 / 倒带 ±3 秒作用的片段，640×360、30fps、H.264（有原声就带 AAC 96k）、`-movflags +faststart`，插带时才加载。目前 Ib 82 秒、挂个爽 29 秒（带原声），SLEIGHT、3D 滑雪各 12 秒（无声）。
- `full.mp4`（可选）：点开放大的 720p 版，和 clip 同一条时间线，放大后从小屏当前位置接着播。
- `loop.mp4`：没有 clip 时的 3–5 秒循环兜底。

## 实现要点

- **整数倍缩放**：按设备像素算倍率 `s = floor(min(宽×dpr/320, 高×dpr/180))`，画布按原生分辨率绘制、CSS 放大 `s/dpr`，草地铺满整个视口。DOM 文字和按钮的尺寸都是 `--u`（1 原生像素）的整数倍。
- **旋转不糊**：倾斜的磁带用最近邻逐像素预旋转（`rotated()`），不靠 CSS/Canvas 旋转，所以没有半透明边。
- **像素字体进画布**：标签文字按 8 倍字号绘制后取每格中心点，得到和字体设计一致的像素；磁带倾斜时只转外壳，标签文字保持水平。
- **玻璃盖**：底边铰链、4 帧向前翻开。插带 / 退带 / 换带都先开盖；拖着磁带悬停在卡座上会自动开盖。
- **快进 / 倒带**：当前片段前后跳 3 秒，转轮短暂加速，计数器显示播放到第几秒。换作品靠收纳包、曲目单和作品列表。
- **音量滚轮**：倒带和电源之间，横向拖动 / 触控板横滑 / 键盘左右键调节，同时控制音效和视频原声。默认拨在最左（静音），往右拨出声；页面上没有单独的静音按钮。
- **三花猫挂件**：点一下随机左右摆动（方向、幅度、快慢随机），挂件铃铛响，偶尔「喵」一声。
- **声音**：背景是风声 + 草叶沙沙，阵风强度和画面里扫过草地的风浪用同一个公式，声画同步；视频有原声时背景自动压低。音效：拿起 / 放下磁带、飞行呼啸、插带咔哒、玻璃盖开合、退带弹簧、按键、电机启停、快进倒带走带声、电源开关、音量棘轮、猫铃铛、翻纸、屏幕点亮、视频放大。
- **悬停**：按键和音量滚轮悬停时变亮、描琥珀色边，滚轮刻字显示当前音量；按住按键时键帽立刻压下。磁带悬停用欠阻尼弹簧拿起（冲到 5px 再稳在 4px，同时略微扶正）、落下时陷进皮面 1px 再弹回。
- **左上角标题牌**：默认 A 木牌「Grampus 游戏作品集 / MAOLIN LU · 2026」；`?sign=B`（磁带封面卡）、`?sign=C`（草地大字）可预览另两版，`?sign=0` 不显示。手机上收纳包上方放得下就用完整版，放不下退回单行版。
- **草地风动**：静态底色 + 每秒 12 帧重画的草尖和小花，阵风斜扫过草地时草尖压低变亮。
- **防卡死**：所有延时动作挂在渲染循环的同一个时钟上；单帧出错只自愈不停循环；拖拽中途切窗口 / 在窗口外松手会把磁带送回包里；忙碌状态超过 3 秒自动复位。
- **无障碍**：画布只负责画面；磁带、按键、曲目、链接都是真实的 `<button>` / `<a>`，可 Tab 聚焦，有文字标签；状态变化通过 `aria-live` 播报。
- **首屏**：HTML + CSS + JS + 两套字体共约 60 KB（gzip），视频插带时才设 `src`，缩略图悬停才加载。
- 默认静音；点喇叭后才创建 AudioContext。
